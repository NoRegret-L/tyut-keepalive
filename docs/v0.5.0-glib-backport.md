## Scope and integrity

The 121 files in the original MIT-licensed published crate are preserved, including LICENSE and COPYRIGHT, except the two upstream changes in src/variant_iter.rs: make the out-argument pointer binding mutable and pass a mutable reference to the C function. No GTK, Tauri or other dependency versions are upgraded. Verified Git tree `c064fcd71830730d12645b54228326cefefd6188`; independently derived SHA-256 tree manifest `e8dbbd51b181d6ffc6d5e002bc28334a94760799a200181dedbfc263382076b1`. Check on every platform before building. The application dev dependency on GLib is Linux-only and is used solely by the iterator regression. Linux release-mode testing is necessary because optimizer behavior exposed the unsoundness.

The backport addresses the specific known undefined-behavior mechanism, not all potential GLib/GTK issues. Cargo audit on a path crate may skip registry advisories. Therefore CI audits the real build lock and a separate, provenance-checked copy restoring only GLib's registry identity and original checksum. The known warning may remain visible even after the source fix; do not ignore the advisory or interpret a lower raw warning count as safety. Review any new GLib advisory against the actual backport. Re-evaluate and remove this override when Tauri can use a maintained upstream-compatible release.
