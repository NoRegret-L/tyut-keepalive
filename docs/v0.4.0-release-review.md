## 代码审查

- 凭据：清除失败后旧记录可能在重启后被自动使用；添加不含秘密的清除意图标记，写入失败时报错，删除后读回验证，明确保存新凭据才解除标记。已有系统密钥库迁移保持。文件系统自身故障无法保证标记持久化。
- 校园协议：原有明文 Portal 探测与重定向逻辑可能误判；认证仍固定 HTTPS 主机且拒绝自动重定向。补充重定向方案/用户信息校验和取消检查，DNS 控制台输出脱敏；不改变现有校园网成功判定规则，需真实校园网抓取脱敏样本后设计更可靠的验证。
- 调度：代次校验、单网络任务、暂停/休眠/密码错误准入检查已有单测，已发出请求无法撤回；事件风暴与系统电源回调需实机验证。
- 日志统计：仅结构化事件，轮转、损坏末行恢复和状态转换测试；指标不是校园认证会话。磁盘 I/O/权限故障和跨日期/休眠行为需真实验证。
- UI/托盘/通知：修正更新忙碌期间仍可点击但实际不执行的控件。主题、窗口最小尺寸、原生托盘菜单与通知权限需实机验收。
- 更新：官方版本绑定与内置公钥，默认空公钥；无真实签名端到端测试。GitHub release 构建共享 latest.json，改为矩阵串行并增加每标签并发保护，采用官方 includeUpdaterJson 参数；发布清单核对实际资产、目标后缀、签名版本，仍不代替密码学验证。
- 发布：版本一致性扩展至两个锁文件。工作流仍然是标签触发，未触发标签构建。系统代码签名与公证独立。未改版本号、未配置密钥或发布。
