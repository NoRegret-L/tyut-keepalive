# 脱敏诊断与日志检索

根因：实机异常只能依赖零散截图；直接共享原始日志存在凭据与网络标识泄露风险。采用结构白名单投影而不是对任意字符串做事后敏感信息替换。报告只读取既有 get_status/get_telemetry 和 app version API，不访问文件、不新增 IPC/权限、不发起网络请求，不引入后台定时器。采用后端现有 200 条日志上限，而非新增经验超参数。

状态、日志分别读取；部分读取失败以 null 表示，不复制错误详情。报告只由用户主动生成并预览，复制由用户主动操作，浏览器剪贴板不可用则手动复制。时间戳仍属于使用活动信息。日志筛选是状态、事件类别、文本的交集，匹配数量明确且可重置。不改变认证、重试、暂停、存储或签名更新行为。

回归测试覆盖白名单、异常字段、缺失快照、200 条边界及交集筛选；Windows 实机验证剪贴板权限降级和窄窗口布局。图标使用用户会话中新生成的 TYUT 图样，桌面资源及界面图标同步，动态状态托盘保留。更换安装图标不改变应用标识、MSI GUID、凭据或自启命名。正式发布工作流保持不变。
