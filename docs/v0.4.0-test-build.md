# v0.4.0 独立测试安装包

该工作流只在 develop/v0.4.0 的测试构建配置发生变化时自动运行，或在 GitHub 支持该分支手动触发时运行。先通过同一提交的 Windows、Linux 严格锁定验证，然后生成 Windows x64 MSI、Linux x64 DEB/AppImage。Linux 使用 Ubuntu 22.04 构建以尽量降低 glibc 基线；不承诺兼容所有发行版。没有 Release 写权限、发布标签、签名私钥或自动更新文件。

## 隔离约束

- 配置 src-tauri/tauri.test.conf.json + Cargo feature test-build 必须一起启用；Rust 在插件初始化前验证 identifier，避免测试凭据与正式配置混用。
- 产品名 TYUT Keepalive Test、程序 tyut-keepalive-test、标识 com.tyut.keepalive.test；测试 MSI upgradeCode 为基于测试标识生成的固定 UUID v5。正式配置及 Cargo/package 版本不改，测试安装包单独标为 0.4.0。Linux 测试构建在一次性 checkout 中将 Cargo.toml 与 Cargo.lock 的根包名改为 tyut-keepalive-test（第三方依赖完全不变），避免 Tauri DEB 打包沿用正式版 Cargo 程序名。构建后用 dpkg-deb --fsys-tarfile 检查确切的可执行文件路径，拒绝正式版程序路径。
- Tauri 应用数据、WebView 存储、单实例采用测试 identifier；系统密钥库 service 采用同一编译期 identifier，自启采用独立产品名。
- 测试版不注册 updater，后端更新命令也拒绝；配置覆盖清空公钥和 endpoints，createUpdaterArtifacts=false。独立 dist-test 明确展示测试身份。
- 两个版本不共享应用配置、凭据与自启记录，但使用同一个校园网接口和认证会话，建议不要同时运行两个保活进程。卸载前在测试版关闭自启、清除测试凭据及退出。隔离设计仍需真实安装并存验证。

## 下载与检查

登录 GitHub，打开对应成功的 Actions 运行，下载 Artifacts 中 TYUT-Keepalive-Test-windows-x64 或 linux-x64 压缩包（名称包含完整 commit），解压。保留 30 天，超过期限或仓库设置限制可能不可用。SHA256SUMS.txt 覆盖安装包与 BUILD-INFO.json；该哈希用于传输完整性检查，不等于代码签名。安装前核对 Actions 运行提交与 BUILD-INFO.json。

Windows PowerShell：Get-FileHash -Algorithm SHA256 .\<安装包>.msi，与 SHA256SUMS.txt 相应行比较。Linux 在解压目录运行 sha256sum -c SHA256SUMS.txt。DEB 可用 sudo apt install ./<安装包>.deb 安装；AppImage 在适用系统中 chmod +x 后运行（可能需要 FUSE）。不要对来源不明的包关闭操作系统安全保护。

## 实机验收

1. 与正式版并存安装、卸载；核对各自应用名称、程序路径、数据目录和自启记录。
2. 使用测试账号检查保存、重启读取、清除以及失败后保护；确认不会迁移正式版凭据。正式版原地升级、凭据迁移需另行验收。
3. 认证、暂停、恢复、错误密码、网络切换、休眠唤醒及通知；不要同时运行正式和测试保活。
4. 三主题、窄窗口、托盘、重复启动、退出及日志统计。
5. 检查关于页明确为测试版，更新按钮不可用。

测试包无 Authenticode/公证签名，SHA-256 不替代签名；现有 RustSec 警告仍保留，macOS 不参与本次测试包构建。仅构建成功不代表实机验收通过。

## 本地构建

在一次性新 checkout（无 dist-test）运行 npm ci、python scripts/check_security.py。Windows：先运行 python scripts/prepare_test_build.py。
```sh
npm run tauri -- build --config src-tauri/tauri.test.conf.json --features test-build --target x86_64-pc-windows-msvc --bundles msi -- --locked
```
Linux：仅在一次性 checkout 中运行以下命令（脚本会临时改根包名，不要提交临时 Cargo 文件）：
```sh
python scripts/prepare_test_build.py --linux-package-identity
npm run tauri -- build --config src-tauri/tauri.test.conf.json --features test-build --target x86_64-unknown-linux-gnu --bundles deb,appimage -- --locked
```
