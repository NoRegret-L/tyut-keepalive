# GLib 0.18.5 安全回移实验（非生产补丁）

关联 #3；不依赖 PR #4 合并。RustSec RUSTSEC-2024-0429 影响 VariantStrIter：C 可写出参不能通过 Rust 共享引用传递，否则违反别名/可变性约束，优化构建可能出现未定义行为。官方修复 PR https://github.com/gtk-rs/gtk-rs-core/pull/1343 （commit b5a4071），Debian 已在 2026-08-13 的 rust-glib-0.18 0.18.5-7 回移相同两行修复：https://bugs.debian.org/cgi-bin/bugreport.cgi?bug=1143114 ；补丁：https://sources.debian.org/patches/rust-glib-0.18/0.18.5-7/0007-glib-fix-UB-in-VariantStrIter-impl_get.patch/ 。

方案：不升级 GTK3 或 Tauri；从 crates.io 下载锁定的 0.18.5 crate，以当前 Cargo.lock 中 SHA-256 验证，保留上游许可证。仅在 runner 的临时 git archive 中进行两处精确替换和本地 patch override，验证其他依赖解析版本未改变。使用 release-mode 测试覆盖正反向、跳过、最后元素、空字符串及 UTF-8，执行现有应用库测试并核对实际解析路径。证据 Artifact 仅含源码包、差异、实验锁文件、依赖树和来源记录。工作流只读，无正式/测试发布操作。

本 PR 不修改生产 Cargo.toml、Cargo.lock 或正常构建流程，因此不能宣称已修复正式版。实验成功后应审阅下载源码和许可证，独立审查最小 vendored 补丁或固定可信 commit，保留来源及持续维护记录，然后再提交生产集成 PR、执行三平台严格锁定回归和 Linux 实机验收。RustSec 仍可能对 0.18.5 报警；不能利用 path source 不参与 registry 审计来掩盖风险。禁止全局 ignore 或伪造版本。
