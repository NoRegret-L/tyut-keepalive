## 本次改动
业务直接依赖从 Chrono 改用 RustSec 推荐的 Jiff。已有的 0.2.46 版本继续使用，锁文件仅修改根包依赖引用。系统本地时区、日期、状态时间和 RFC 3339 日志协议不变；不迁移既有数据，不改变调度所用单调时钟。事件日期与时间使用同一时间采样。新增确定性格式测试；三平台严格锁定构建与 RustSec 审计必须通过后才能考虑合并。系统时区解析及历史日志兼容仍需实机验证。

不忽略警告、不伪造版本、不接受未知第三方补丁。GLib 的已知缺陷仍未修复。参考官方 [补丁](https://github.com/gtk-rs/gtk-rs-core/pull/1343) 和 [Tauri 跟踪](https://github.com/tauri-apps/tauri/issues/12048)。需要从可信来源获得完整 0.18.5 包并核对来源/许可证、最小补丁、Linux release-mode iterator 测试及完整三平台回归，才能接受回移；当前环境无法获取并独立校验原始 crate。发布门禁见 #3。

参考：[Chrono 公告](https://rustsec.org/advisories/RUSTSEC-2026-0543.html)、[zvariant 公告](https://rustsec.org/advisories/RUSTSEC-2026-0370.html)、[GLib 公告](https://rustsec.org/advisories/RUSTSEC-2024-0429.html)、[Jiff 文档](https://docs.rs/jiff/latest/jiff/).
