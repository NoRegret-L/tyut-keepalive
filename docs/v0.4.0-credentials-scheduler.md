# v0.4.0 安全凭据与后台调度（开发分支）

- 使用 keyring 3.6.3 的 Windows Credential Manager / macOS Keychain / Linux Secret Service（启用 crypto-rust）。凭据库不可用时明确报错，停止自动认证，不写入新的 XOR 文件。Linux 需要可用、已解锁的 Secret Service 会话。
- 保留原 Portal 协议的 XOR 编码；安全库内保存单条完整记录。旧版 Tauri app_data_dir/config.enc 按写入、读回比较、删除顺序迁移；冲突或失败时保留旧文件并提示。此前非 Tauri 版本的其他安装路径不自动扫描。
- 清除先删除旧文件再删除系统记录，避免旧文件复活凭据。删除失败会停止当前进程的认证，但可能仍有未删除的凭据，请修复权限后再次清除。
- 调度器独占凭据管理，消息通道在截止时间或事件到来时唤醒。单一网络工作任务；凭据版本隔离过期结果。账号切换立即使旧结果失效，并在网络请求阶段之间协作取消；已进入 HTTP 发送阶段的请求不能保证撤回，也不会主动注销校园网。
- 密码错误停止自动认证；手动重连可明确发起重试。保留 10 秒初始、1 小时最大退避和 10 分钟正常检查周期。前端监听状态事件，移除每秒 IPC 轮询。
- 验证：cargo test --manifest-path src-tauri/Cargo.toml；npm run check:html；Windows/macOS/Linux 实际凭据库、校园网实地认证及窗口隐藏/恢复仍需验证。引入依赖后需重新生成并提交 Cargo.lock（不能用未更新的 lockfile 执行 --locked）。
