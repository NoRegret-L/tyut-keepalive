# v0.4.0 UI 与发布验证

- 保留 Tauri 原生标题栏、现有 IPC 和状态事件；不新增前端框架、CDN、外部资源或敏感数据存储。
- 四页：连接概览、运行记录、设置、关于。使用 CSS Grid/Flex、变量与 prefers-color-scheme；主题偏好只保存 system/light/dark 字符串，系统模式实时响应系统主题。
- 运行记录仅使用当前 WebView 会话收到的状态事件（最多 100 条，用于限制内存），不作为持久化日志、连接统计或真实在线时长。
- 无后端时仅允许预览界面及切换主题；后台操作禁用。凭据表单不回显密码，操作期间禁用重复提交。
- 开发 CI 为 Windows/Linux；macOS 兼容性 CI 独立运行。发布标签必须先通过三平台复用检查，安装包上传到草稿，全部构建成功后才公开发布。
- 验证：npm run check:html；node --check dist/main.js；node --test scripts/test_ui.mjs；真实 WebView 主题、布局、键盘交互和系统凭据库仍需实机测试。
