# 本地运行日志、统计、托盘及通知

- 结构化 JSONL 事件日志由 Rust 后台调度器记录，使用已有 Serde；不持久化原始 HTTP 错误、账号、密码、IP、MAC 或请求 URL。两个 1 MiB 文件轮转（约 2 MiB 磁盘预算）；界面最多显示 200 条记录，支持筛选与搜索。每日累计统计随事件持久化，进程重启恢复最近有效聚合。存储失败不停止保活，界面提示统计可能不完整。
- 认证确认数只计明确 Portal 成功/已在线响应，不将不明确响应后的网络探测成功当作认证成功；并非新的登录会话数。观测中断仅计已观察在线到网络探测失败的边沿，不将检查中、凭据更改或通用传输错误算作断网。在线时长从本进程首次确认在线开始，使用单调计时，显示截至最近刷新值；遇到无法分类的传输错误时停止累计，下一次确认在线后重新开始，不虚构断网次数。现有网络探测规则仍可能误判，不能证明校园网实际在线会话时长。
- 系统托盘按状态更新图标、菜单和提示，支持重连和打开设置；平台不支持提示或托盘时降级。
- 官方 tauri-plugin-notification，仅由后台触发，默认关闭，用户主动开启后保存偏好；状态边沿去重。系统通知权限、显示样式和平台行为需实机验证。
- 引入通知插件后，开发 CI 临时允许解析新依赖并上传 Linux Cargo.lock 产物，然后运行 --locked 验证；正式发布仍使用原有锁定验证门禁。取得 CI 产物后提交锁文件，并恢复日常开发严格锁定。
